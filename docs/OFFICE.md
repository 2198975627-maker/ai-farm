# 办公室网页规范

农场办公室是全员群聊：经理在群里发任务，员工领任务，
单独私聊汇报给经理，经理在群里统筹最终结果交付给你。

## 招募弹窗（按你的要求，分两路）

点“招募”后先选接入方式，表单随之变化：

### API 付费 / 免费 API
- 字段：名字、厂商、模型 ID、Base URL、环境变量名
- **没有 Key 输入框。** 页面上不出现 Key 明文。
  旁边写一句：“Key 只放你电脑的环境变量里，这里只填它的名字。”
- 保存后图标角标：`付费·API` 或 `免费·API`

### 网页 / 订阅制
- 字段：名字、厂商、模型 ID、登录页 URL、用量页 URL
- 一个大按钮：**登录一次**
  - 点开厂商自己的登录页，你在那登自己的号
  - 回来后显示“已登录”，蓝条挂用量页链接
- 保存后图标角标：`免费·网页` 或 `付费·订阅`

## 其他规范（已实现的办公室沿用）

- 左边一排图标，图标下是身份 + 蓝条（额度）。
- 蓝条点开跳厂商用量页；订阅制只显示当前周期，API 显示到余额归零，
  小于等于 10% 变红。
- 任务进度：派单 → 接单 → 进行中 → 交付 → 验收。
- 交付卡片有“验收通过 / 打回重做”。
- 技能中心独立一页：技能列表、谁在用、经理判断分配。
- 转交只允许转给不同厂商的 Agent（不许同款复制，不得多开同一家 token 池）。
