# 安全

- API Key 只放环境变量。永远不要写进 `agents.yaml`、工单、聊天记录、
  截图、git 提交。`.gitignore` 已屏蔽 `agents.yaml`、`.env`、
  `~/.ai-farm/sessions/`。
- 网页登录只在厂商自己的页面做。本项目永远不问你要密码，
  不收验证码，不存密码。
- 会话文件只存在本地，换电脑重新登，丢了重新登，不要备份到公开处。
- 发现 Key 泄露：立即去厂商后台作废重建，只删文件不够。
- 开源前自查：`grep -r` 搜一遍你的邮箱、手机号、Key、订单号、
  真实账号名，确认没有混进示例配置和文档。
- 订阅与付费：绑卡、付费、续费永远由你本人在厂商页面点，
  本项目不代付、不代绑卡。
