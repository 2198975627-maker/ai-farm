# 花名册模板 Roster — 你自己招募谁就填谁

> **开源框架说明**：本文件是通用花名册模板。下载本项目后，具体的经理、免费员工、CLI 工具或桌面端 Agent 全部由你自己在办公室页面（`➕ 招募新 AI Agent`）或 `agents.yaml` 中按需招募。
>
> **状态分三档**：✅ 已核实可用 / ❓ 待确认 / ⛔ 今日额度已耗尽

## 第 1 层 总管（唯一入口）

| 成员 | 角色 | 干什么 | 通道 |
|---|---|---|---|
| 总管 (Chief) | 统筹总管 | 唯一入口：听任务、拆单、派单、记账、质检、整合、汇报 | 对话入口 |

## 第 2 层 经理层 — 动脑（示例占位，请换成你自己的强推理模型）

| 成员 | 角色 | 强项 | 通道 / 状态 |
|---|---|---|---|
| *(自行招募)* | 架构 / 前端经理 | 规划、大块设计、代码审查（只看 diff/摘要） | API 或 订阅网页 |
| *(自行招募)* | 代码实现经理 | 复杂逻辑、最终合入验收 | API 或 CLI |

## 第 3 层 员工层 — 动手（免费农场轮换制，请招募你自己的多家免费资源）

| 成员 | 适合干什么 | 通道 / 备注 |
|---|---|---|
| *(自行招募)* | 批量翻译、批量分类打标 | 免费 API（Key 只放系统环境变量） |

| *(自行招募)* | 读写本地文件夹、文档/表格初稿 | 桌面应用端（`@工单.md` 文件信箱协同） |

## 排班铁律
1. **一个图标 = 一个模型/独立额度池**：同一家既有付费又有免费，必须拆开建两个图标。
2. **一厂商一免费号**：不靠多开同家小号绕额度；转交任务只许转给不同厂商。
3. **小活不请经理**：员工失败先换另一名免费员工，连续 2 次失败才升级经理。
4. **法力值必须真实**：查不到就写「额度未填」，绝不编造百分比。
