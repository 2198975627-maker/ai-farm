新手友好说明：本农场开箱即用，不强制下载任何额外桌面工具！以下 4 种基础调用方法已全部内置；如果你想更进一步全自动解放双手，可按需自由选择下方两个「可选加强组件」。

内置 4 种基础调用方法（在任务私聊窗一键触发）

1. API 直接调用：在系统环境变量配置好 Key 后，点 真调执行 自动并行执行并统计 Token，失败自动切换别家员工。
2. CLI 命令行调用（如 Codex CLI）：点 真调执行 自动在本机工作区运行命令并收回 git diff。
3. 免费聊天网页派单：点 打开网页 + 复制指令，自动打开官网并复制好工单模板，切过去粘贴即跑。
4. 桌面端半自动派单（如 WorkBuddy / 豆包 PC）：点 导出 .md + 复制 @触发句，生成工单文件后粘贴给客户端读本地目录，改完点 抓取本地 git diff 摘要 汇报。

可选加强自动化 ①：网页端「AI 农场传令兵」插件（免下载外部程序）

不想手动在网页间来回粘贴？可自由选择加载本项目自带的轻量 Chrome/Edge 扩展（位于仓库 browser-extension/ 目录），打开网页自动填表发送、一键抓回最新回复。
3 步启用教程：
1) 浏览器打开 chrome://extensions（Edge 为 edge://extensions），开启右上角「开发者模式」；
2) 点击「加载已解压的扩展程序」，选择本项目的 browser-extension 文件夹；
3) 以后在农场点「打开网页 + 复制指令」，插件会自动帮你填入发送，完成后点右下角「抓最新回复交回农场」。

可选加强自动化 ②：桌面端静默驱动（引用开源项目 vercel-labs/agent-desktop）

对于没有公开 API/CLI 的桌面应用（如 WorkBuddy、豆包电脑版），如需从半自动升级为后台静默自动填入与发送，可自由选择下载安装 Vercel 开源的 agent-desktop（Apache-2.0 协议，读取 Windows 无障碍控件树，0 Token 消耗、不抢鼠标焦点）。不安装也完全不影响正常使用本农场！
前往 vercel-labs/agent-desktop 官方下载页 查看 Releases 安装包
使用教程（3 步）：
1) 从上方官方链接下载安装 agent-desktop 并将其放入系统 PATH；
2) 打开桌面端（如 WorkBuddy），运行 agent-desktop snapshot --app WorkBuddy -i --json 获取输入框与发送按钮的 @ref 编号；
3) 配合本农场的 导出 .md，用 agent-desktop type <ref> "@tasks/inbox/TASK-xxx.md" 与 click 实现后台静默投喂。
