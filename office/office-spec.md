## 布局

- 左边一排团队名单：圆头像 + 身份标签 + 状态点 + 图标下蓝条（额度），
  分组是拖放目标，可搜索，底部招募。点头像右边出档案，底下团队总览。
- 中间全员群聊（见下），右边档案 + 总览。
- 桌面三栏；手机先任务列表，再全屏聊天。
- 拖图标到别的楼层换岗：2 楼经理、1 楼员工、院子休息。

## 群聊流程

全员在一个大群聊里。经理在群里发任务卡片；员工点“领取”，
群里留一条认领记录；员工做好后单独私聊汇报给经理，
群里只留 🔒 提示，汇报正文不出现在群里；经理点“统筹交付”，
把总结果以 `🏁 最终交付 · 总结果 · 给 Gao` 卡片发回群里。
Gao 也能在群里说话，身份是“你（Gao）”。
顶部进度：已认领 X/总数、已汇报 X/总数、已交付、已验收。
按钮：`🧪 一键塞入通用示例任务`（4 个通用示例轮换）。
交付卡片：`✅ 验收通过 / ↩ 打回重做`。
进度：派单 → 接单 → 进行中 → 交付 → 验收。

## 厂商与身份

- 群头有厂商条；每个档案有“独立身份”（所属厂商 / 真实模型 / 账号额度）。
- 每个 Bot 都是真实的别家大模型，各走各家账号和额度，不是共用一个 token 池。
- @人派活，@ 出的名字加粗。私聊里“转交”只允许转给不同厂商。

- 每图标下一小条蓝条，像游戏法力值。订阅制只显示当前刷新周期，
  API 显示到余额归零；≤10% 变红 + 闪烁 + 档案警告 + 顶部汇总。
- 点蓝条/档案按钮跳该账号的实时查额度页。
- 已核实链接：Gemini → gemini.google.com/usage；
  DeepSeek → 开放平台用量页；ChatGPT → Settings Usage；
  Grok → Settings → Usage；千问免费网页 → tongyi.aliyun.com；
  千问付费 API → 阿里百炼控制台；K-EXAONE → EXAONE 平台；

## 招募弹窗（新规范，两路）

- API（付费/免费 API）：名字、厂商、模型 ID、Base URL、环境变量名。
  页面上没有 Key 输入框，不出现 Key 明文。角标 `付费·API` / `免费·API`。
- 网页/订阅：名字、厂商、模型 ID、登录页 URL、用量页 URL，
  大按钮“登录一次”，跳厂商自己的登录页，回来显示“已登录”。
  角标 `免费·网页` / `付费·订阅`。
